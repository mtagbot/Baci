pip install PyMuPDF python-bidi Pillow

python3 tools/analyze_exam_pdf.py exams/فایل.pdf \
        -o exams/فایل-import.json \
        --subject ریاضی --grade هفتم

خروجی: فایل JSON با فرمت baci-bank-import@1 که در پنل مدیریت،
بانک سوالات ← «ایمپورت سوالات آزمون» بارگذاری می‌شود.

گردش کار پیشنهادی:
1) فایل PDF نمونه سوالات را در پوشه exams مخزن قرار دهید.
2) از من (دستیار) بخواهید آن را تحلیل کنم — فایل *-import.json
   ساخته و کنارش در پوشه exams قرار می‌گیرد.
3) در پنل مدیریت: بانک سوالات ← ایمپورت سوالات آزمون ←
   فایل JSON را انتخاب کنید (یا اگر روی هاست در پوشه exams
   باشد از فهرست انتخاب کنید) ← پیش‌نمایش ← انتخاب سال/ماه/
   دبیر طراح/درس ← تأیید و ثبت.
پاسخ‌نامه انتهای PDF به‌طور خودکار نادیده گرفته می‌شود.
