==========================================================
  به‌روزرسانی v4.69.0 — ۴ بهبود بخش آزمون‌ها
==========================================================

۱) دسته‌بندی‌های پیش‌فرض آزمون آنلاین:
   - دسته‌بندی آزمون‌ها: ۱۲ ماه سال (مهر تا شهریور) با رنگ‌های
     متمایز — خودکار ساخته می‌شوند اگر جدول خالی باشد.
   - دسته‌بندی سوالات: ۱۴ درس اصلی متوسطه اول (آموزش قرآن،
     پیام‌های آسمان، فارسی، نگارش، عربی، زبان انگلیسی، ریاضی،
     علوم تجربی، مطالعات اجتماعی، فرهنگ و هنر، کار و فناوری،
     تفکر و سبک زندگی، تربیت بدنی و سلامت، آمادگی دفاعی).
   - ساخت خودکار هم از صفحه دسته‌بندی‌ها و هم از بانک سوالات
     انجام می‌شود (یک‌بار، فقط وقتی جدول خالی است — دسته‌های
     موجود شما دست نمی‌خورند).
   - امکان افزودن دسته جدید مثل قبل باقی است (فرم افزودن در
     صفحه دسته‌بندی‌ها؛ فقط مدیر).

۲) رفع بن‌بست بانک سوالات امتحانات حضوری:
   صفحه exam-question-bank.php اکنون نوار بالای بخش امتحانات
   را دارد: «برنامه امتحانی | صندلی و کلاس | چاپ | بانک سوالات
   (فعال) | بازگشت به امتحانات» — دیگر بن‌بست نیست.

۳) رفع رفتن برگه زیر نوار ابزار در ویرایشگر زنده:
   قبلاً فاصله برگه از بالا عدد ثابت 58px بود؛ وقتی نوار
   تنظیمات (که آیتم زیاد دارد) دو یا سه خطی می‌شد، برگه زیر
   آن می‌رفت. اکنون ارتفاع «واقعی» نوار با JS اندازه‌گیری و
   به‌صورت متغیر CSS اعمال می‌شود (در لود، تغییر اندازه پنجره
   و با تاخیر برای فونت‌ها). پنل‌های ویرایش و بانک سوال هم با
   همان متغیر جابه‌جا می‌شوند.

۴) چاپ پایه‌ای آزمون حضوری:
   در تب «چاپ» ستون جدید «چاپ پایه‌ای (همه کلاس‌های پایه)»
   اضافه شد: با یک کلیک، طراحی همان آزمون برای «تمام
   دانش‌آموزان همه کلاس‌های آن پایه» تکثیر و چاپ می‌شود —
   مستقل از این که طراحی برای کدام کلاس انجام شده بود.
   (در ویرایشگر همان دکمه «تکثیر برای همه و چاپ» را بزنید؛
   لیست دانش‌آموزان این بار کل پایه است.)

فایل‌های تغییر یافته (۵ فایل):
  1) online-exam-categories.php   (پیش‌فرض‌ها؛ شامل v4.62)
  2) online-question-bank.php     (پیش‌فرض‌ها؛ شامل v4.62)
  3) exam-question-bank.php       (نوار تب + بازگشت؛ شامل v4.68)
  4) exam-print.php               (اصلاح فاصله نوار ابزار + برگه)
  5) exams.php                    (ستون چاپ پایه‌ای؛ شامل v4.61)

نصب:

۱) هر ۵ فایل را در همان مسیرها جایگزین کنید.
۲) SQL دستی لازم نیست؛ دسته‌های پیش‌فرض بار اول خودکار ساخته
   می‌شوند (فقط اگر جدول مربوطه خالی باشد).

----------------------------------------------------------
تست پیشنهادی:
----------------------------------------------------------
- آزمون آنلاین → دسته‌بندی‌ها: ۱۲ ماه و ۱۴ درس دیده شوند؛
  افزودن دسته جدید هم کار کند.
- امتحانات → بانک سوالات: نوار تب‌ها بالای صفحه باشد و
  «بازگشت به امتحانات» کار کند.
- طراحی زنده آزمون: برگه زیر نوار ابزار نرود (پنجره را باریک
  کنید تا نوار چندخطی شود — برگه باید پایین‌تر برود).
- تب چاپ: «چاپ برای کل پایه X» را بزنید — تعداد برگه‌ها برابر
  همه دانش‌آموزان پایه در همه کلاس‌ها باشد.
