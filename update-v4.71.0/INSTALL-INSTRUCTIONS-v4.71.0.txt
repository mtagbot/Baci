۱) نمایش فقط «نام خانوادگی» دبیر خارج از پنل مدیریت:
   تابع سراسری جدید teacher_family_name() در includes/functions.php:
   - پیشوندهای احترام (استاد/آقای/خانم/دکتر/مهندس/سید و...)
     حفظ می‌شوند و بعد از آن فقط نام خانوادگی می‌آید.
   - نام‌های خانوادگی مرکب (مثل «حسینی نژاد») سالم می‌مانند.
   نمونه: «آقای علی احمدی» → «آقای احمدی»
          «استاد محمد حسینی نژاد» → «استاد حسینی نژاد»
   اعمال‌شده در:
   - هدر پورتال دبیر (teacher_nav.php): «استاد احمدی»
   - نشان نام دبیر در منوی کاربری (header.php)
   - لیست آزمون‌های آنلاین دانش‌آموز (student-online-exams.php)
   - لیست آزمون‌های آنلاین برای بیننده دبیر (online-exams.php —
     مدیر همچنان نام کامل می‌بیند)
   - بخش امتحانات exams.php برای بیننده غیرمدیر (لیست امتحان‌ها،
     جدول فعال‌سازی، دراپ‌داون دبیر، آزمون‌های کلاسی طراحی‌شده)
   - پیام تایید ورود دبیر در ربات (bot_webhook_engine.php)
   پنل مدیریت (مدیر لاگین‌شده) همه‌جا نام کامل را می‌بیند.

۲) چاپ پایه‌ای مدیریت با خانه مشترک (exams.php → تب چاپ):
   مثل پنل دبیر: ردیف‌های «ماه + پایه + درس یکسان» پشت‌سرهم
   مرتب می‌شوند و ستون «چاپ پایه‌ای (مشترک کلاس‌های پایه)» فقط
   «یک خانه مشترک با rowspan» برای کل گروه دارد — دیگر برای هر
   ردیف دکمه جداگانه نیست. دکمه: «چاپ پایه‌ای هشتم (۳ کلاس)».

۳) تغییر متن کاشی پنل دبیر:
   «طراحی سوالات تشریحی» → «طراحی آزمون» (teacher_nav.php).

تست پیشنهادی:
----------------------------------------------------------
- پورتال دبیر: بالای صفحه «استاد [نام خانوادگی]» باشد.
- پنل دانش‌آموز → آزمون‌های مجازی: نام طراح فقط نام خانوادگی.
- پنل مدیریت: همه‌جا نام کامل دبیر بماند.
- امتحانات (مدیر) → تب چاپ: برای درس/پایه‌ای که چند کلاس دارد،
  یک خانه مشترک سبز «چاپ پایه‌ای (n کلاس)» روی همه ردیف‌ها.
- کاشی‌های پنل دبیر: «طراحی آزمون» به‌جای «طراحی سوالات تشریحی».
