## اصلاحات

### ۱. اجرای طراحی زنده آزمون در مینی‌اپ/مرورگر دیگر

در `exam-print.php`:

- بررسی token طراحی آزمون قبل از خطای «غیرمجاز» انجام می‌شود.
- اگر صفحه از مینی‌اپ بله/تلگرام به مرورگر دیگری منتقل شود، لینک دارای `dt` معتبر اجازه دسترسی می‌دهد.
- بنابراین صفحه طراحی سوالات نباید با پیام «غیرمجاز» بسته شود.

### ۲. حذف کامل حالت تاریک

طبق درخواست، حالت تاریک سیستم حذف/غیرفعال شد:

- دکمه «تغییر پوسته» از منوی کاربری حذف شد.
- `assets/js/main.js` همیشه theme را روی `light` تنظیم می‌کند.
- کلاس `dark` از `html` و `body` حذف می‌شود.
- در `includes/header.php` قبل از بارگذاری CSS حالت روشن اعمال می‌شود.
- CSS نیز متغیرهای dark را عملاً به مقادیر روشن برمی‌گرداند.

### ۳. خواناتر شدن تصویر کارنامه ربات‌ها

در `includes/report_image.php`:

- رنگ نمرات اصلاح شد:
  - زیر ۱۰: قرمز
  - ۱۰ تا ۱۵: نارنجی
  - ۱۵ به بالا: سبز
- متن وضعیت نیز متناسب با بازه نمره تغییر می‌کند.
- اندازه بخشی از فونت‌های جدول کمی بزرگ‌تر شد.

### ۴. بهبود هدر موبایل در حالت روشن

در `assets/css/style.css` و `includes/header.php`:

- اسکریپت اعمال حالت روشن قبل از رندر صفحه اضافه شد.
- نمایش هدر موبایل فشرده و روشن باقی می‌ماند.
