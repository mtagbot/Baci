# سیستم مدیریت کارنامه دانش‌آموزی

## امکانات نسخه نهایی

- PHP خالص + MySQL
- پنل دانش‌آموز و پنل مدیریت مدرن و واکنش‌گرا
- ایمپورت فایل CSV مطابق نمونه `Report.csv`
- نمودارهای تحلیلی با **Chart.js محلی** و بدون CDN
- خروجی **Excel** و **PDF واقعی با TCPDF**
- پشتیبانی از **چند ادمین** با نقش‌ها و سطح دسترسی پیشرفته
- نصب‌یار خودکار با فایل `installer.php`
- **migration-updater.php** برای ارتقای نسخه‌های قبلی بدون نصب مجدد
- **لاگ فعالیت مدیران**
- **پشتیبان‌گیری و بازیابی دیتابیس** از داخل پنل
- **اعلان‌ها و نوتیفیکیشن‌های سیستمی** + ارسال ایمیل/پیامک از طریق تنظیمات
- **API داخلی برای اپ یا موبایل** با Access Token و Refresh Token
- **بازیابی کامل یا انتخابی جدول‌ها از بکاپ**
- **جستجو و صفحه‌بندی Ajax** در مدیریت دانش‌آموزان
- **تاریخ‌های شمسی و ایرانی** در رابط کاربری
- **امکان مسدودسازی مشاهده/دریافت کارنامه برای دانش‌آموز یا به‌صورت گروهی بر اساس سال/ماه/کلاس**
- **تحلیل پیشرفته مقایسه کلاس‌ها و ماه‌ها با فیلتر**
- **ایمپورت چندمرحله‌ای (Wizard) با پیش‌نمایش، تشخیص ابهام، Resolve دستی و تایید آپدیت بر اساس کد ملی**
- **پشتیبانی از CSV و XLSX** برای ایمپورت ساختاریافته
- **قالب CSV ساختاریافته آماده دانلود + راهنمای متنی و نسخه چاپی راهنما**
- **Import Session versioning** و امکان ادامه نشست‌های نیمه‌تمام
- **صف ایمپورت فایل‌های بزرگ** + Worker قابل اجرا با Cron
- **REST API مدیریتی برای Import / Queue / Resolve**
- **سامانه پیامکی حرفه‌ای** با پشتیبانی از Providerهای ایرانی و ارسال تکی/گروهی/کمپینی
- **تنظیمات ظاهری پیشرفته** شامل رنگ‌ها، تم تاریک/روشن، لوگو، آیکون و فونت‌های میزبانی‌شده روی هاست

## روش راه‌اندازی پیشنهادی

### روش ۱: با نصب‌یار خودکار
1. پوشه `student-report-system` را روی هاست یا لوکال قرار دهید.
2. آدرس `installer.php` را در مرورگر باز کنید.
3. اطلاعات دیتابیس، تنظیمات مدرسه و مدیر اصلی را وارد کنید.
4. نصب‌یار به‌صورت خودکار:
   - دیتابیس را می‌سازد
   - فایل `sql/database.sql` را ایمپورت می‌کند
   - فایل `config/database.php` را تنظیم می‌کند
   - مدیر اصلی را می‌سازد
5. پس از نصب، وارد `index.php` شوید.

### روش ۲: نصب دستی
1. فایل `sql/database.sql` را ایمپورت کنید.
2. فایل `config/database.php` را تنظیم کنید.
3. اگر هنوز مدیری وجود ندارد، از تب **ساخت مدیر اولیه** در `index.php` مدیر را ایجاد کنید.

## نقش‌های مدیریتی

### 1) سوپر ادمین
- دسترسی کامل به همه بخش‌ها
- مدیریت سایر مدیران
- تنظیمات سیستم

### 2) مدیر آموزشی
- مدیریت دانش‌آموزان
- مدیریت کلاس‌ها و دروس
- مشاهده کارنامه‌ها
- ایمپورت CSV

### 3) ناظر / مشاهده‌گر
- مشاهده داشبورد
- مشاهده کارنامه‌ها

> علاوه بر نقش‌ها، امکان افزودن **مجوزهای تکمیلی** برای هر مدیر نیز وجود دارد.

## نکات مهم

- فایل `assets/vendor/chart.umd.min.js` به‌صورت محلی ذخیره شده و نیاز به اینترنت ندارد.
- کتابخانه `TCPDF` نیز در پوشه `vendor/tcpdf/` قرار دارد.
- اگر فایل CSV فاقد کد ملی باشد، دانش‌آموز با هویت موقت ساخته می‌شود و مدیر بعداً اطلاعات او را تکمیل می‌کند.
- پس از نصب موفق، فایل `config/installed.lock` ایجاد می‌شود.
- برای نصب مجدد می‌توانید `installer.php?force=1` را باز کنید.
- برای پروژه‌های قدیمی، فایل `migration-updater.php` را بعد از ورود مدیر اجرا کنید.
- برای ایمپورت فایل‌های xlsx، فعال بودن افزونه‌های `ZipArchive` و `SimpleXML` روی هاست توصیه می‌شود.
- برای پردازش خودکار صف ایمپورت، فایل `cron/import-queue-worker.php` را در Cron Server اجرا کنید.
- صفحه‌های جدید مدیریتی:
  - `backups.php`
  - `activity-logs.php`
  - `migration-updater.php`
  - `admin-ajax.php` (endpoint داخلی Ajax)
- مستندات API:
  - `api/docs.php`
  - `api/openapi.json`
  - `api/openapi-admin-import.json`
- API داخلی در مسیر زیر در دسترس است:
  - `api/index.php?action=config`
  - `api/index.php?action=student_login`
  - `api/index.php?action=admin_login`
  - `api/index.php?action=refresh_token`
  - `api/index.php?action=me`
  - `api/index.php?action=reports`
  - `api/index.php?action=report_detail`
  - `api/index.php?action=notifications`
  - `api/index.php?action=admin_dashboard`
- REST API مدیریتی Import:
  - `api/admin-import.php?resource=sessions`
  - `api/admin-import.php?resource=queue`
  - `api/admin-import.php?resource=queue-process`
  - `api/admin-import.php?resource=preview-state`
  - `api/admin-import.php?resource=preview-execute`
  - `api/admin-import.php?resource=resolve-student-edit`
