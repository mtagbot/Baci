## تغییرات اصلی

### ۱. بهینه‌سازی جدی ویرایشگر زنده آزمون

در `exam-print.php`:

- طراحی زنده فقط روی دانش‌آموز اول انجام می‌شود.
- هنگام چاپ، صفحات طراحی‌شده دانش‌آموز اول clone می‌شوند و فقط سربرگ هر دانش‌آموز جایگزین می‌شود.
- PDF برای هر دانش‌آموز دوباره رندر نمی‌شود.
- صفحات PDF فقط یک بار در cache تبدیل می‌شوند و با URLهای تصویر استفاده می‌شوند.

### ۲. حذف صفحه اضافی در ویرایشگر آزمون

دکمه جدید اضافه شد:

- `حذف صفحه اضافی`

عملکرد:

- از آخرین صفحه شروع می‌کند.
- فقط صفحه خالی از سوال و منبع را حذف می‌کند.
- صفحه اول هرگز حذف نمی‌شود.

### ۳. ذخیره دقیق طراحی آزمون در سیستم

در طراحی ذخیره‌شده، اکنون موارد زیر هم ذخیره می‌شوند:

- سوالات
- فیلدهای سربرگ
- دست‌نویس‌ها
- برش‌ها
- چینش صفحات منبع
- تنظیمات ظاهری صفحه مثل ارتفاع سربرگ، اندازه عکس، عرض/ارتفاع کادر سوال و ...

بنابراین کاربر دیگر با مرورگر/سیستم متفاوت هم می‌تواند همان طراحی را بازیابی و ادامه دهد.

### ۴. نقش جدید معاون اجرایی

به سیستم نقش جدید اضافه شد:

- `معاون اجرایی`

در مدیریت دبیران، مدیر می‌تواند برای هر دبیر این نقش را فعال کند.

فایل‌ها/تغییرات:

- `includes/school_roles.php`
- `import-teachers.php`
- `teacher-panel.php`
- `includes/header.php`
- `executive-panel.php`

### ۵. پنل معاون اجرایی

فایل جدید:

- `executive-panel.php`

دسترسی‌ها:

- مدیریت دانش‌آموزان
- امتحانات
- مدیریت کارنامه‌ها
- مدیریت دروس، فقط کلاس‌ها و دروس

### ۶. دسترسی نقش معاون اجرایی به صفحات لازم

برای نقش معاون اجرایی، دسترسی لازم به صفحات زیر فراهم شد:

- `students.php`
- `exams.php`
- `reports.php`
- `classes.php`
- `courses-management.php`
- `reports-management.php`

در `classes.php` برای معاون اجرایی فقط تب‌های کلاس‌ها و دروس مجاز است.

### ۷. دیتابیس

به `sql/database.sql` اضافه شد:

```sql
ALTER TABLE teachers ADD COLUMN is_executive tinyint(1) NOT NULL DEFAULT 0;
```
