## محتوای نسخه

این نسخه شامل آخرین وضعیت پروژه و اصلاحات مربوط به ویرایشگر زنده آزمون و فایل‌های منبع آزمون است، از جمله:

- تنظیم کنتراست تصویر صفحات PDF/تصویر منبع
- تنظیم روشنایی تصویر صفحات PDF/تصویر منبع
- حذف پس‌زمینه سفید تصویر منبع
- تنظیم جابه‌جایی افقی/عمودی تصویر منبع
- تنظیم برش از چهار طرف
- حفظ تنظیمات تصویر منبع در طراحی ذخیره‌شده
- محدودسازی تصاویر سوال به کادر همان سوال و کادر ویرایشگر متن سوال
- پنجره ویرایش حرفه‌ای تصویر سوال
- ویرایشگر ریاضی self-hosted
- سازوکار طراحی زنده آزمون و تکثیر طراحی برای دانش‌آموزان
