سه مشکل گزارش‌شده و رفع آن‌ها:

۱) دکمه‌های سفید روی پس‌زمینه سفید در پنل دبیر:
   علت: کلاس‌های Tailwind مانند bg-gradient-to-l / from-green-600 /
   bg-white / text-green-700 اصلاً در CSS این پروژه تعریف نشده‌اند؛
   بنابراین کارت گرادیان سبز نمی‌گرفت و دکمه‌ها سفید-روی-سفید
   می‌شدند.
   راه‌حل: هدر پنل دبیر با CSS مستقل (خارج از Tailwind) بازسازی شد:
   - کارت با گرادیان سبز واقعی (linear-gradient)
   - دکمه‌ها به شکل «شبکه‌ای مثل اپلیکیشن‌های موبایل» (Grid):
     کاشی‌های هم‌اندازه با آیکون بزرگ بالای متن، افکت hover،
     چیدمان خودکار auto-fill و در موبایل ۳ ستون — بدون بهم‌ریختگی.
   - دکمه «خروج» از این بخش حذف شد (در منوی «کاربری» موجود است).

۲) فوتر سمت چپ صفحه در دسکتاپ/تبلت:
   علت: در includes/footer.php شرط بستن تگ‌های ساختار فقط برای
   مدیر و دانش‌آموز بود؛ برای دبیر <div class="flex flex-1"> بسته
   نمی‌شد و فوتر داخل ردیف فلکس کنار سایدبار می‌افتاد.
   راه‌حل: دبیر هم به همان شرط اضافه شد؛ فوتر مثل بقیه پنل‌ها
   پایین صفحه قرار می‌گیرد.

۳) نام کاربر سفید روی پس‌زمینه سفید در پنجره «کاربری»:
   علت: همان مشکل بند ۱ — کلاس‌های bg-green-600 / bg-amber-600 /
   bg-primary در CSS پروژه وجود ندارند.
   راه‌حل: رنگ پس‌زمینه Badge نام کاربر برای هر سه نقش با رنگ
   صریح تنظیم شد:
   - مدیر: آبی (var(--primary))
   - دانش‌آموز: سبز #059669
   - دبیر: کهربایی #d97706
   با فونت سفید کاملاً خوانا.
