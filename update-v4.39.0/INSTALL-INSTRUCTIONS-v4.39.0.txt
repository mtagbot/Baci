فایل‌های داخل بسته (۱ فایل):
--------------------------------------------------------------------
1) classes.php   → جایگزین

روش نصب: جایگزینی + Ctrl+F5. بدون تغییر دیتابیس.
(این فایل شامل تمام تغییرات نگارش 4.38.0 هم هست.)

--------------------------------------------------------------------
۱) تب «کلاس‌ها» — ایجاد کلاس جدید
--------------------------------------------------------------------
● «پایه تحصیلی» → لیست انتخابی (پایه‌های موجود سیستم + هفتم تا
  دوازدهم استاندارد).
● «شماره کلاس» → لیست انتخابی ۱ تا ۱۲.
● «نام کلاس» دیگر تایپ نمی‌شود؛ سیستم آن را خودکار از ترکیب
  پایه + شماره می‌سازد (مثلاً هفتم + ۱ = هفتم1) و پیش‌نمایش
  زنده آن را نشان می‌دهد.
● جلوگیری از ثبت کلاس تکراری در همان سال تحصیلی اضافه شد.

--------------------------------------------------------------------
۲) تب «دروس» — تعریف درس
--------------------------------------------------------------------
● «نام درس» → لیست انتخابی از تمام دروس موجود سیستم (برنامه
  هفتگی + دروس ثبت‌شده). گزینه «+ تعریف درس جدید...» فقط در
  صورت نیاز یک فیلد متنی باز می‌کند.
● «کد درس» → کاملاً خودکار توسط سیستم (DRS-0001، DRS-0002، ...)؛
  کاربر آن را وارد نمی‌کند و فقط پیش‌نمایش کد بعدی را می‌بیند.
  کد یکتا بودن آن هم توسط سیستم کنترل می‌شود.
● «پایه / رشته» → لیست انتخابی (با گزینه «عمومی - همه پایه‌ها»).

--------------------------------------------------------------------
۳) تب «برنامه هفتگی و دبیران» (مدیریت جامع)
--------------------------------------------------------------------
● فیلتر جدید «کلاس» به صورت لیست انتخابی به نوار فیلترها اضافه
  شد (سال، کلاس، دبیر، درس، جستجو).
● فرم سبزرنگ «افزودن زنگ جدید» بالای جدول: کلاس، روز هفته،
  زنگ (۱ تا ۸)، درس و دبیر — همگی لیست انتخابی.
● ویرایش داخل ردیف (Inline Edit): هر ردیف جدول دکمه «ویرایش»
  دارد؛ با کلیک، همان ردیف تبدیل به ۵ لیست انتخابی می‌شود:
    - کلاس        → انتخابی
    - روز هفته    → انتخابی (شنبه تا پنجشنبه)
    - زنگ         → انتخابی (زنگ ۱ تا ۸)
    - درس تحصیلی  → انتخابی
    - دبیر        → انتخابی (+ گزینه «تعیین نشده»)
  سپس «ذخیره» یا «انصراف».
● دکمه «حذف» هر ردیف با تأیید، مثل قبل کار می‌کند.
● اگر مقدار فعلی یک ردیف در لیست‌ها نبود (داده قدیمی)، همان
  مقدار به لیست اضافه می‌شود تا با ویرایش از بین نرود.

--------------------------------------------------------------------
تست سریع:
--------------------------------------------------------------------
1) تب کلاس‌ها → پایه «هفتم» + شماره «۲» → پیش‌نمایش «هفتم2» →
   ثبت → در جدول ظاهر شود. ثبت دوباره همان → پیام خطای تکراری.
2) تب دروس → از لیست یک درس انتخاب کنید → ثبت → پیام سبز با کد
   خودکار (DRS-xxxx). گزینه «تعریف درس جدید» → فیلد متنی باز شود.
3) تب برنامه هفتگی → روی «ویرایش» یک ردیف بزنید → ۵ لیست
   انتخابی ظاهر شود → دبیر را عوض کنید → ذخیره → ردیف به‌روز
   شود. فرم بالای جدول → زنگ جدید اضافه کنید.
