# اصلاحیهٔ V4.220.0 — نمایش ماه و روز برنامهٔ امتحان

- پیام برنامهٔ امتحانی دانش‌آموز در ربات ماه انتخاب‌شده را در عنوان و روز هفته را پیش از تاریخ هر آزمون نمایش می‌دهد.
- تنظیم ماه دبیران سه حالت دارد: جدیدترین ماه (پیش‌فرض)، انتخاب دستی، یا نمایش همهٔ ماه‌ها.
- انتخاب ماه خودکار دبیران از همان رتبه‌بندی ماه‌های برنامهٔ دانش‌آموز استفاده می‌کند.

این اصلاحیه فایل‌های داخل بسته را در ریشهٔ برنامه جایگزین می‌کند. پیش از نصب نسخهٔ پشتیبان تهیه شود.
