  ۱) بازطراحی کامل صفحات ورود   ۲) بهینه‌سازی پایگاه داده و منطق سیستم

این بسته شامل به‌روزرسانی v4.30.0 هم هست؛ حتی اگر آن را نصب نکرده
باشید، با نصب همین بسته همه‌چیز کامل می‌شود.

--------------------------------------------------------------------
فایل‌های داخل بسته (۸ فایل):
--------------------------------------------------------------------
1) index.php                    → جایگزین — صفحه ورود جدید (بخش‌های
                                  ورود/منطق دست نخورده؛ فقط بخش نمایش login)
2) admin-login.php              → جایگزین — صفحه ورود کادر مدرسه با طراحی جدید
3) db-optimizer.php             → جدید — ابزار «سلامت پایگاه داده» ⭐
4) includes/functions.php       → جایگزین — کش تنظیمات (کاهش شدید کوئری‌ها)
5) includes/header.php          → جایگزین — شامل تغییرات 4.30.0 + لینک منوی
                                  «سلامت پایگاه داده» در بخش سیستم
6) includes/footer.php          → جایگزین — (همان 4.30.0؛ برای کامل بودن بسته)
7) assets/css/ui-modern.css     → جایگزین — استایل‌های جدید صفحات ورود اضافه شد
8) assets/js/ui-modern.js       → (همان 4.30.0؛ برای کامل بودن بسته)
9) sql/database.sql             → جایگزین — فقط برای نصب‌های جدید (ایندکس‌ها)
10) این فایل راهنما

--------------------------------------------------------------------
روش نصب:
--------------------------------------------------------------------
1) همهٔ فایل‌ها را در همان مسیرها آپلود/جایگزین کنید.
2) وارد پنل مدیریت شوید → منوی «سیستم» → «🩺 سلامت پایگاه داده».
3) روی «⚡ اعمال ایندکس‌های حیاتی» کلیک کنید (یک بار؛ کاملاً امن،
   هیچ داده‌ای تغییر نمی‌کند).
4) اگر شمارندهٔ «رکورد یتیم» یا «تکراری» بزرگ‌تر از صفر بود، دکمه‌های
   پاکسازی را بزنید.
5) در پایان «🚀 ANALYZE + OPTIMIZE جداول» را یک بار اجرا کنید.

⚠ توصیه: قبل از پاکسازی، از بخش پشتیبان‌گیری یک Backup بگیرید.
(ابزار فقط رکوردهای بلااستفاده را حذف می‌کند و رکوردهای دارای
کارنامه/سابقه را هرگز حذف نمی‌کند، اما پشتیبان همیشه خوب است.)

--------------------------------------------------------------------
بخش ۱ — صفحه ورود جدید:
--------------------------------------------------------------------
● کارت شیشه‌ای (Glass) با پس‌زمینهٔ گرادیانی و لوگوی مدرسه
  (اگر در تنظیمات، لوگو آپلود کرده باشید همان نمایش داده می‌شود).
● تب‌های Segmented مدرن به‌جای تب‌های خطی قدیمی.
● فیلدها با آیکون داخلی، دکمهٔ نمایش/مخفی‌سازی رمز (👁)،
  inputmode عددی برای موبایل (کیبورد عددی باز می‌شود)،
  autocomplete استاندارد مرورگر.
● کادر سوال امنیتی جذاب‌تر و فشرده‌تر.
● دکمه‌های بزرگ لمس‌پذیر + اسپینر خودکار هنگام ارسال.
● هر دو صفحه: index.php (دانش‌آموز/استعلام/دبیر) و admin-login.php
  (مدیر/دبیر).
● منطق ورود، CSRF، کپچا و Throttle دقیقاً همان قبلی است — فقط
  ظاهر عوض شده.

--------------------------------------------------------------------
بخش ۲ — ممیزی و بهینه‌سازی دیتابیس (نتایج بررسی کامل):
--------------------------------------------------------------------
پس از تحلیل کامل ۴۷ جدول سیستم و کوئری‌های تمام صفحات:

الف) نتیجهٔ ممیزی جداول:
   • هیچ جدول «اضافه» قابل حذفی وجود ندارد. همهٔ جداول به ماژول‌های
     فعال (کارنامه، انضباطی، امتحانات حضوری/آنلاین، ربات‌ها، مشاوره)
     متصل هستند. جداول کم‌استفاده (مثل bale_bot_state/telegram_bot_state)
     توسط موتور ربات‌ها به‌صورت داینامیک استفاده می‌شوند و باید بمانند.
   • مشکل واقعی: «نبود ایندکس روی جداول پرحجم» و «رکوردهای یتیم» بود
     که هر دو با ابزار جدید حل می‌شود.

ب) ایندکس‌های حیاتی (۱۴ ایندکس) که ابزار اضافه می‌کند:
   • students(national_id, academic_year) → ورود دانش‌آموز/استعلام
     (پرترددترین کوئری سیستم — تا ده‌ها برابر سریع‌تر با رشد داده)
   • students(academic_year, class_name) و students(status)
   • reports(student_id, academic_year, term) → کارنامه‌های دانش‌آموز
   • reports(academic_year, class_name) → رتبه‌بندی کلاسی
   • reports(academic_year, term, report_month) → گزارش‌های دوره‌ای
   • report_grades(report_id, subject_name) → نمرات و تحلیل درس
   • report_locks / classes / activity_logs / sms_logs /
     notifications / api_tokens / student_discipline_records
   همهٔ ایندکس‌ها idempotent هستند (اگر باشند، دوباره ساخته نمی‌شوند).

ج) پاکسازی رکوردهای موازی/بلااستفاده (۱۱ نوع اسکن):
   • نمرات بدون کارنامه، کارنامه‌های بدون دانش‌آموز
   • قفل‌ها و موارد انضباطی دانش‌آموزانِ حذف‌شده
   • پاسخ‌ها/تلاش‌ها/سوالات/لاگ‌های آزمون آنلاینِ بی‌مرجع
   • تخصیص‌های امتحان حضوری بی‌مرجع، درخواست‌های مشاورهٔ بی‌مرجع
   • توکن‌های API و توکن‌های ربات منقضی‌شده
   • دانش‌آموزان تکراری (کدملی+سال یکسان) — فقط اگر هیچ کارنامه/
     سابقه‌ای ندارند حذف می‌شوند؛ بقیه برای بررسی دستی گزارش می‌شوند.
   • کلاس‌های تکراری (نام+سال یکسان)

د) بهینه‌سازی منطق (کد):
   • get_setting اکنون کل جدول settings را «یک بار در هر درخواست»
     می‌خواند و کش می‌کند. قبلاً فقط هدر هر صفحه ۱۵+ کوئری جدا
     می‌زد؛ الان ۱ کوئری. در کل سیستم ده‌ها کوئری در هر بارگذاری
     صفحه حذف شد.
   • sql/database.sql برای نصب‌های تازه از ابتدا ایندکس‌دار شد.

هـ) داشبورد سلامت:
   • حجم داده/ایندکس هر جدول، موتور و کلیشن، ردیف‌های تقریبی،
     فضای آزاد قابل بازپس‌گیری، هشدار جداول غیر InnoDB/utf8mb4.
   • توصیه: ماهی یک بار این صفحه را باز کنید و اگر موردی قرمز/زرد
     بود دکمهٔ مربوطه را بزنید.

--------------------------------------------------------------------
تست سریع بعد از نصب:
--------------------------------------------------------------------
1) خروج از سیستم → صفحه ورود جدید (کارت شیشه‌ای + تب‌های جدید).
2) ورود دانش‌آموز آزمایشی → کیبورد عددی موبایل + دکمه چشم رمز.
3) admin-login.php → همان طراحی برای مدیر/دبیر.
4) منوی سیستم → «🩺 سلامت پایگاه داده» → اعمال ایندکس‌ها → رفرش:
   شمارندهٔ «ایندکس حیاتی غایب» باید صفر و سبز شود.
5) سرعت صفحات (مخصوصاً لیست دانش‌آموزان و کارنامه‌ها) محسوس‌تر
   خواهد بود؛ با رشد داده‌ها تفاوت چند برابر می‌شود.
