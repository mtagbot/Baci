==========================================================
  به‌روزرسانی v4.59.0 — صدای بازر تایید / خطا برای اسکنر
==========================================================

صداهای جدید (مانند دستگاه‌های کارت‌خوان/گیت):

  ✅ تایید (حضور به‌موقع):
     چایم دو نُتی بالارونده (E6 ← B6) — صدای روشن و مثبت که
     کاملاً «تایید شد» را می‌رساند.

  ⏰ هشدار (تأخیر یا تگ تکراری):
     دو بوق مربعی میانی — جلب توجه، اما نه خطا.

  ❌ عدم تایید / خطا (تگ نامعتبر، خطای سرور، خطای شبکه):
     بازر بم و خشن دوتایی (BZZT-BZZT با موج sawtooth و افت
     فرکانس) — کاملاً متمایز و منفی.

  لرزش (در گوشی/تبلت‌هایی که پشتیبانی کنند):
     تایید: یک لرزش کوتاه — هشدار: دو لرزش — خطا: دو لرزش بلند.

نکته مهم مرورگرها:
  مرورگرهای موبایل پخش صدا را تا اولین لمس صفحه قفل می‌کنند.
  به همین دلیل:
  - با اولین لمس/کلیک روی صفحه، صدا به‌طور خودکار فعال می‌شود.
  - تا قبل از آن، پیام «برای فعال شدن صدای بازر، یک بار صفحه
    را لمس کنید» زیر پنل نمایش داده می‌شود و بعد از لمس محو
    می‌شود.
  - همه صداها با Web Audio API ساخته می‌شوند — هیچ فایل صوتی
    لازم نیست و آفلاین هم کار می‌کند.
