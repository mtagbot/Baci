# گزارش بررسی Release_V1.0

تاریخ ساخت نخستین بسته: 2026-09-17؛ آخرین بازسازی: 2026-09-19 (بازسازی دوم: شامل دو اصلاح «قفل فوکوس بی‌نهایت اسکنر» و «به‌روزرسانی آنلاین دسکتاپ»). هدف: دو نصب کامل از صفر، با تغییرات سایت تا 4.152.0 و دسکتاپ تا 2.83.0.

## بازسازی دوم ۱۹ سپتامبر ۲۰۲۶ (اصلاح اسکنر + به‌روزرسانی آنلاین دسکتاپ)

- دو بستهٔ اصلاحی تازه منتشر و در زنجیرهٔ ساخت ثبت شدند: `scanner` (قفل فوکوس روی بی‌nهایت، جایگزین نسخهٔ «فوکوس نزدیک» با همان نام) و `desk-update` (به‌روزرسانی آنلاین نرم‌افزار دسکتاپ از روی سایت). هر دو **آخرین** حلقهٔ ترتیب ادغام‌اند تا هیچ تغییر قدیمی‌تری روی‌شان نوشته نشود.
- ترتیب ادغام اکنون: `svg-responsive` → `student-workflow` → `preview-navigation` → `fast-ui` → `mobile-hubs` → `report-tools` → `settings-health` → (دسکتاپ: `reports-layout`) → `bot-outbox` → (دسکتاپ: `optimized-sync` → `event-sync`) → `recovery-ui` → **`scanner`** → **`desk-update`**. یعنی اکنون **۱۰ بستهٔ اصلاحی سایت** و **۱۳ بستهٔ اصلاحی دسکتاپ** درون بسته است.
- خروجی‌ها: `Release_V1.0-Site.zip` (۳٬۴۸۳٬۷۲۵ بایت، `d2e287178e3247b2aa22cb7bd0b6e126001c2ed24fee736e6f17329fce80a903`)، `Release_V1.0-Desktop.zip` (۱۷٬۱۰۲٬۹۲۳ بایت، `18bc74f4c6ded4b6fa06c8465e05a59e67b30494c3885546e11dd3349877ae8c`) و `Release_V1.0-SHA256SUMS.txt` (بازنویسی شد).
- **۳۲ سوئیت رگرسیون روی پوشهٔ stage دسکتاپ و سایت** سبز است (سوئیت تازهٔ «به‌روزرسانی آنلاین دسکتاپ» اضافه شده)، **۱۱ گروه آزمون بسته‌بندی کامل** سبز، **۵۸ بررسی نصب تازهٔ دسکتاپ** سبز، و **۹ آزمون بستهٔ به‌روزرسانی دسکتاپ** به‌همراه ۵ آزمون بستهٔ اسکنر سبز.
- دو نکتهٔ ساخت‌وساز: پوشهٔ `uploads/` هرگز در بسته نمی‌رود (به همین دلیل محافظ `uploads/desktop-updates/.htaccess` در زمان اجرا و با بازشدن صفحهٔ انتشار ساخته می‌شود)، و `SchoolDeskPro.exe` همیشه از `launcher.c` کامپایل می‌شود.
- نسخهٔ داخلی‌ها همان سایت 4.152.0 / دسکتاپ 2.83.0 است؛ این دو اصلاح، اصلاحی‌اند نه نسخهٔ کامل.

## آنچه اجرا شد

- **۳۱ سوئیت رگرسیون روی خروجی کامل سایت و ۳۱ سوئیت روی خروجی کامل دسکتاپ**؛ PHP واقعی 8.3.33 در WebAssembly و SQLite داخل حافظه. دادهٔ آزمون فقط پس از اجرای نصب‌یار واقعی، داخل محیط مجزای آزمون ساخته می‌شود و وارد ZIP نمی‌شود.
- **۱۱۲ بررسی نصب/امنیت/یکپارچگی**: نصب تازهٔ SQLite؛ نصب تازه روی **MySQL واقعی 5.7.29**؛ CSRF، رمز ضعیف، کلید مالک هاست، اطلاعات اتصال اشتباه، عدم fallback، ایجاد تنها مدیر انتخابی، عدم وجود اطلاعات مدرسهٔ نمونه، قفل نصب مجدد و `force=1`، حفظ تنظیمات، تکرار مهاجرت‌ها، کلید تصادفی جدید، احراز هویت هر دو API همگام‌سازی، ورود واقعی مدیر، صفحات اصلی، کنترل مسیرهای خصوصی روتر دسکتاپ، تولید PDF واقعی با فونت فارسی و رد تنظیمات ناقص دیتابیس.
- **۱۱ گروه آزمون بسته‌بندی کامل**: فایل‌های ضروری، نبود اطلاعات و اسرار نصب‌شده، اسکیمای خالی و فعال‌ماندن triggerها، شاخص صحیح MySQL، انطباق بایتی آخرین فایل‌های تمام وصله‌ها، حفظ تفاوت‌های مستند دسکتاپ در مبنای کامل، حذف کلید تاریخی مشترک، SHA256 تک‌تک فایل‌ها، مسیرهای ایمن ZIP، ساختار اجرایی PE32+ ویندوز و درون‌بودن بسته‌های اصلاحی منتشرشده.
- **۹ سوئیت بسته‌بندی تاریخی** نیز بدون بازسازی یا تغییر ZIPهای تاریخی عبور کردند.
- لانچر از سورس فعلی با Zig 0.14.1 برای Windows x64 ساخته شد؛ فرمت PE، معماری و زیرسیستم GUI کنترل شد. این بررسی جای اجرای واقعی روی ویندوز را نمی‌گیرد.
- وابستگی TCPDF 6.11.4 با شناسهٔ blobهای Git تثبیت‌شده و Chart.js 4.5.1 با SHA256 تثبیت‌شده به‌صورت محلی همراه بسته قرار گرفتند.

## اصلاحات ویژهٔ نصب کامل

1. نصب‌یار قدیمی با نصب‌یار قفل‌شونده و دارای CSRF/کلید مالک هاست جایگزین شد؛ حساب و رمز پیش‌فرض توزیع نمی‌شود.
2. داده‌ها و تنظیمات مدرسهٔ نمونه از SQL حذف شدند، بدون حذف INSERTهای داخل بدنهٔ triggerهای همگام‌سازی.
3. خطای واقعی شاخص `student_discipline_records` در اسکیمای قدیمی MySQL اصلاح شد: شاخص اکنون به ستون موجود `created_at_jalali` اشاره می‌کند.
4. اتصال خراب/تنظیمات ناقص دیتابیس دیگر به دیتابیس یا مشخصات اتصال حدسی تبدیل نمی‌شود.
5. هر دو API همگام‌سازی کلید همان نصب را از فایل محرمانهٔ مشترک می‌خوانند؛ کلید قدیمی جاسازی‌شده در بسته‌ها وجود ندارد. endpoint اصلی نیز بر مبنای آخرین وصلهٔ 4.101، شامل آرشیو طراحی و انتخاب صفحات PDF، حفظ شده است.
6. کتابخانهٔ محلی جاافتادهٔ Chart.js و موتور PDF/فونت مربوط به TCPDF اضافه شدند؛ فایل Python تحلیل PDF نیز در هر دو بسته موجود است.
7. پوشه‌های خصوصی محافظت می‌شوند؛ heartbeat همگام‌سازی محلی فقط در نسخهٔ دسکتاپ اجرا می‌شود، نه صفحهٔ دریافت کلید سایت.
8. تست‌های قدیمی از وابستگی به شناسهٔ ثابت دانش‌آموز نمونه، شمارش دادهٔ نمونه برای صفحه‌بندی و کلید تاریخی ثابت جدا شدند؛ بررسی رفتاری حذف یا ضعیف نشده است.

## محدودیت‌ها و آنچه ادعا نمی‌شود

- محیط اجرا Linux است؛ **EXE روی Windows بومی اجرا نشده** و باز/بسته‌شدن پنجرهٔ Edge/Chrome، SmartScreen، چاپگر فیزیکی و دوربین گوشی در این نوبت آزمون نشده‌اند.
- تست MySQL با 5.7.29 انجام شد، نه MySQL 8.x. این نسخهٔ MySQL منقضی است و فقط ابزار آزمایش سازگاری بود؛ روی هاست تازه نسخهٔ پشتیبانی‌شده به کار ببرید و نصب را در محیط آزمایشی خودتان کنترل کنید.
- PHP داخلی ویندوز همان 8.1.34 بستهٔ مبناست و شاخهٔ منقضی است؛ فقط برای استفادهٔ محلی مورد اعتماد، نه میزبانی عمومی. تغییر عمدهٔ runtime بدون آزمون ویندوز انجام نشده است.
- قواعد Apache/Nginx باید در هاست مقصد اجرا/کنترل شوند؛ بررسی واقعی HTTP در این محیط برای Apache/Nginx انجام نشده است. قواعد روتر PHP دسکتاپ در آزمون اجرا شدند.
- ابزارهای اختیاری تحلیل/تبدیل PDF منبع، سرویس‌های پیامک/ربات و مجوزهای دوربین وابستگی‌های خود را دارند؛ توضیح در README-FA.md است. خروجی کارنامهٔ PDF با TCPDF همراه، واقعاً آزمون شد.

## بازتولید

```sh
python3 scripts/build-full-release.py
SITE=.cache/release-v1/package/site bash scripts/run-tests.sh
SITE=.cache/release-v1/package/SchoolDeskPro/www bash scripts/run-tests.sh
node tests/test-full-release-install.mjs
# فقط با MySQL آزمایشی محلی و رمز آزمایشی در فایل ignored:
RELEASE_TEST_MYSQL=1 node tests/test-full-release-install.mjs
PYTHONDONTWRITEBYTECODE=1 python3 tests/test-full-release-packaging.py
```

محدوده و شیوهٔ ساخت در `release-v1.0/BUILD.md`، راهنمای نصب در `release-v1.0/README-FA.md` و شناسهٔ فایل‌ها در `Release_V1.0-SHA256SUMS.txt` و manifestهای داخل ZIP است.
