## تغییرات

### وسط‌چین عمودی در هر چهار خروجی

شامل A4 و A3، با نام خانوادگی/نام جدا یا یکجا، و تمام سلول‌های عنوان کلاس، سرستون، اسامی، شماره و جمع:

- قالب بعضی سلول‌ها `vAlign=bottom` داشت؛ اکنون **همهٔ سلول‌ها `vAlign=center`** دارند.
- خط قبلی تقریباً به ارتفاع ردیف بود؛ حتی با تغییر تراز سلول، خط بزرگ فضای خالی برای جابه‌جایی نداشت.
  فقط در سلول‌های جدول، فاصلهٔ خط از exact بزرگ به **single/auto** تغییر کرده است.
- اندازهٔ قلم علامت پایان پاراگراف با بزرگ‌ترین قلمِ متن واقعی همان پاراگراف هماهنگ می‌شود؛
  قلم پنهانِ بزرگ‌تر نباید خط نام کوچک را پایین ببرد.
- تراز متن در خط نیز center است. هیچ جابه‌جایی دستی baseline، superscript یا فشرده‌سازی حروف اضافه نشده است.

**ارتفاع ردیف‌ها همچنان exact است** و از قبل برای حروف تا دو برابر اندازهٔ قلم فضا دارد.
بودجهٔ یک صفحه، اندازهٔ قلم متن، عرض‌ها، حاشیهٔ صفر، padding صفر، تعداد دانش‌آموزان و کلاس‌ها تغییر نکرده‌اند.
رفتار پاراگراف عنوان و پاراگراف خالیِ انتهایی از نظر فاصلهٔ خط تغییر نکرده است.

### جابه‌جایی دو عدد سال در بالای برگه

جای دو عدد سال نسبت به خروجی قبلی برعکس شده است؛ مثلاً دو بخش 1405 و 1406 جایشان عوض می‌شود.
فقط مقدار دو جای‌نگهدار موجود جابه‌جا می‌شود؛ ترتیب runها، جهت RTL، فاصله‌های عنوان و جای جمع کل تغییر نمی‌کند.
این تبدیل برای سال فعلی سیستم خودکار است؛ تنظیم سال تحصیلی و داده‌های مدرسه عوض نمی‌شوند.

لیست کلاسی دبیر و کدهای کلاس مدرسه دست‌نخورده‌اند. چهار دانلود A4/A3 و سقف یک صفحهٔ لیست کل مدرسه باقی مانده‌اند.

### نکتهٔ فنی دربارهٔ آزمون مرورگر

docx-preview 0.4 اندازهٔ قلم `pPr/rPr` را نادیده می‌گیرد و پاراگراف را در اندازهٔ پیش‌فرض ۱۲pt مرورگر نگه می‌دارد،
حتی وقتی قلم runها ۲ تا ۷pt است. آزمون، اندازهٔ واقعی علامت پاراگراف را از XML همان DOCX روی عنصر متناظر اعمال می‌کند؛
تطابق یک‌به‌یک پاراگراف‌ها نیز بررسی می‌شود. اندازهٔ کاغذ، ردیف‌ها، تراز سلول، حاشیه و قلم runها در این تطبیق تغییر نمی‌کنند.
این تطبیق برای بررسی فاصلهٔ خط نسبی لازم است و جایگزین موتور Microsoft Word نیست.

```sh
export SITE=/absolute/path/to/installed/SchoolDeskPro/www
export PATCH=update-v4.152.0
bash scripts/run-tests.sh
python3 scripts/release-rosters.py
python3 tests/test-roster-packaging.py

# آزمون اختیاری مرورگر؛ نصب وابستگی‌ها و کتابخانه‌های سیستمی Chromium لازم است.
npm install --prefix .cache/browser playwright @sparticuz/chromium docx-preview
export BROWSER_MODULES="$PWD/.cache/browser/node_modules"
node tests/test-roster-a4-browser.mjs
# BROWSER_FONT=/absolute/path/to/reference.ttf برای آزمایش فونت دیگر
```

Microsoft Word واقعی/LibreOffice و TTF دقیق `2 Titr` در محیط آزمون در دسترس نیستند.
فونت اصلی باید روی دستگاه مقصد نصب باشد؛ آزمون مرورگر تضمین نمایش یکسان همهٔ Wordها و فونت‌های جایگزین نیست.
